# Les Jeunes Explorateurs

Site de présentation de l’association Les Jeunes Explorateurs, hébergé avec GitHub Pages.

## Organisation du dépôt

- `index.html`, `notre-histoire.html`, `vos-dons.html`, etc. : les pages du site.
- `assets/css/` : toutes les feuilles de style.
- `assets/js/` : les scripts du site, des formulaires, du thème et de l’application installable.
- `assets/images/` : le logo, les portraits et les illustrations.
- `docs/` : la documentation de la base de données et des paiements Stripe.
- `supabase/` : les migrations et fonctions sécurisées côté serveur.
- `manifest.webmanifest` et `service-worker.js` : la version installable de l’application mobile.
- `CNAME` : la configuration du nom de domaine pour GitHub Pages.

## Publication

Envoyez vos modifications sur la branche reliée à GitHub Pages. Le site sera alors mis à jour automatiquement sur `lesjeunesexplorateurs.fr`.
