# Images du site

Déposez ici les images utilisées par le site.

Pour les portraits de la page « Notre histoire », utilisez idéalement ces noms :

- `marvin-erichot.jpg`
- `tiphaine-quintrix.jpg`

Dans le code HTML, le chemin correspondant sera par exemple :

```html
<img src="assets/images/marvin-erichot.jpg" alt="Marvin Erichot" />
```

Préférez une photo au format JPG ou WebP, cadrée verticalement, et optimisée (moins de 1 Mo si possible) pour conserver un site rapide.

Les versions optimisées actuellement utilisées par le site sont :

- `sortie-musee-enfants.jpg` pour la photo principale ;
- `logo-petits-explorateurs-512.png` pour le logo affiché dans les pages ;
- `favicon-64.png` pour l’icône du navigateur ;
- `apple-touch-icon.png` pour les raccourcis iOS.
